# Ключевые функции приложения «Домашняя библиотека»

1. Добавление книги вручную (название, автор, год издания, ISBN, жанр).
2. Поиск книг по автору, названию или жанру.
3. Учёт статуса чтения (прочитано / в процессе / планирую прочитать).
4. Экспорт списка книг в форматы CSV и PDF.
5. Статистика по библиотеке (количество книг, авторов, жанров).
