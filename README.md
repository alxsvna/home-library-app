# Домашняя библиотека

Приложение для учёта книг домашней библиотеки.

## Описание

Позволяет добавлять книги, искать по автору и жанру,
отслеживать статус чтения и вести статистику.

## Установка

1. Клонировать репозиторий
2. Установить зависимости: pip install -r requirements.txt
3. Запустить: python app.py
